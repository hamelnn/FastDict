# 验证范围

以下按版本记录截至 2026-10-18 的验证结果。源码重构、原生接口模拟与设备实测不能互相替代。

## 0.5.0 发布准备

0.5.0 汇集下列三轮源码审查与界面改动。发布目标为 Windows x64 安装包 / 便携 ZIP、macOS 通用 DMG / 应用 ZIP、Android ARM64 debug APK，以及 iOS ARM64 / Intel 模拟器 ZIP。打包与上传结果需以本次构建记录和 Release 附件为准；本节不提前记录成功。iOS 模拟器包不能安装到真机，没有已签名 IPA 或 TestFlight 分发。

下面保留各轮验证发生时的结果：347 / 323 / 290 是不同阶段的完整测试总数，不能相加；旧版本设备测试也不等于 0.5.0 真机验收。

## 2026-10-18 全项目设计审查与优化（纳入 0.5.0）

审查覆盖 React 任务编排与设置、翻译协议 / OCR / 本地存储、Rust 截图与认证、Swift / Kotlin 移动桥接，以及构建脚本和 CI。保留此前未提交的修复和界面改动。

- **交互隔离**：修正设置 / 弹窗内 `Ctrl+Enter` 误发原文、长按快捷键反复重启请求，以及连接指示器错误引用其他服务的问题。拖入图片不会穿透配置页或弹窗。模板与编辑器改为互斥状态；原生输入遇到未配置服务时保留编辑草稿。模态框限制焦点并在关闭时恢复。
- **流式响应**：首段仍立即显示，后续片段按动画帧合并，避免每个网络片段都刷新整个工作区。停止、错误、复制、分享与方向交换同步取出完整缓冲；单测以 1,000 个碎片验证顺序与合并次数，未把它换算为设备速度提升比例。SSE 改为仅扫描新增片段，容量按单事件检查。
- **OCR**：队列等待期间取消立即结束调用，不必等前一个任务完成；图片缓冲区通过 transferable 移交 Worker，减少复制。真实浏览器仍执行打包的 Tesseract Worker / WASM / 模型，检查模型损坏后的释放与恢复。
- **历史完整性**：去除成功译文超过 100,000 字符即静默截断的规则。完整单条记录超过 JSON 容量时明确失败，原有历史保持，正常容量内淘汰旧条目。
- **截图时序**：抓屏前隐藏窗口、抓屏后布置全屏分别在 UI 线程内统一执行；执行时核对会话，取消后的迟到任务不能重新显示覆盖层。新增确定性交错测试，且核对当前锁定的 Tauri / Wry 调度源码及锁释放顺序；不将这些结果记为真实截图验收。
- **账号状态**：连接与注册列表从一次凭据快照得到，减少重复系统保险库访问；成功的模型目录请求返回后也核对当前连接，避免切换 / 断开期间的旧响应覆盖状态。
- **构建 / 开发**：移动交互入口支持设备参数、`--open` / `--host`，不再忽略 `--target`；初始化与编译不要求可启动的模拟器 runtime，iOS 真机 SDK / Rust 可独立检查。Windows 尊重调用者的 Rust 环境，默认目标跟随实际编译器。脚本夹具与本机工具链发现通过；未在 Mac / iPhone 执行新增入口。
- **验证结果：347 项通过，0 跳过**（167 核心、31 构建脚本、88 Playwright、61 Rust），比上一轮增加 24 项。最终完整 Playwright 用时约 1.7 分钟；前端生产构建、TypeScript、Windows GNU `--locked` 原生编译及 `git diff --check` 通过。旧配置保存竞态测试已改为模拟原生剪贴板事件，继续验证保存期间的新请求会在配置提交后取消，不再依赖已修复的弹窗快捷键穿透行为。
- **验证边界**：本轮没有真实账号登录或计费推理、Windows GUI 截图 / 安装验收、macOS / iOS / Android 设备实测，也没有重新打包或发布。已有设备验证只代表对应历史版本。GNU 打包临时调整清单、主组件体量和工具链固定等剩余设计限制列在 [架构与性能](architecture.md#尚待改进)。

## 0.4.0 官方 Sign in with ChatGPT（Windows 预发布）

- 已将 Windows / macOS 桌面订阅入口改为 FastLingo 自己的官方 OAuth 登录，不再启动 Codex CLI、不读取其凭据、不调用 ChatGPT 私有 `backend-api`。旧服务类型标记保留以兼容配置，但须用户重新授权。
- 已通过 **178 项自动化测试**：54 项核心、19 项构建脚本、60 项前端交互和 45 项原生测试。TypeScript、Vite 生产构建与 Windows 原生正式构建通过，最终 NSIS 安装包与便携 ZIP 已生成。
- 原生测试包含 11 项认证、23 项 Responses、2 项浏览器入口与 9 项已有测试。认证覆盖状态与回调绑定、PKCE、ID token 验签及身份字段、加密存储、提交取消竞态和刷新账号绑定等；自动化使用合成身份，不代替真实授权。
- Responses 检查覆盖订阅请求参数、账号模型目录、UTF-8 / SSE 分片、完整成功事件、流中额度错误、拒绝与工具输出、取消和超时等。12 项新增解析回归覆盖 HTTP 200 缺少 MIME 时的受限兼容、无效终结状态、完整输出交叉核验及错误脱敏等。最终规则要求明确成功且无错误的 `response.completed`，将累积译文与最终文本或 `response.output_text.done` 核验；显式空最终输出须由匹配的完整 done 文本佐证，并保留未携带 `output` 字段的简式终态兼容。断流、错误和不匹配的文本均不能记为完成。
- Windows 登录和用量入口统一使用系统 URL 处理器，在长期运行的主线程派发。浏览器入口实测打开 Chrome 中的 ChatGPT 用量页及“使用 ChatGPT 登录 FastLingo - OpenAI”页面，没有新增资源管理器窗口；取消登录后按钮恢复，应用拥有的监听 socket 数量从 1 变为 0。
- GitHub 首轮 CI 的唯一失败是用量入口交互测试在异步调用前立即读取计数；改为等待实际原生调用后，定向重复 12 次通过。该修改不改变应用行为。
- 用户已亲自在系统浏览器完成 FastLingo 的官方 OAuth 授权，实时账号目录提供 `gpt-6-luna`。
- HTTP 200 缺少 `Content-Type` 时仅允许验证合法 SSE 事件的兼容路径，其他响应仍拒绝。实测曾收到 `subscription_sharing_usage_limit_exceeded`，用户自行处理用量限制后继续翻译。该代码可能来自套餐或应用限制，不能据此断言整个套餐已耗尽或推算重置时间。[官方恢复要求](https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery)。
- **最终 Windows 便携包实测通过**：从最终 ZIP 解压并运行 `release/smoke-0.4.0-verified/FastLingo.exe`，ProductVersion 为 `0.4.0`，可执行文件 SHA-256 为 `505944506075279adfa04057d8d8e0a3de0289cdbb9853eed1c9d636afc9c32b`。`Hello, world.` → `你好，世界。`，界面显示总耗时约 5.30 秒、首字约 5.04 秒。
- **真实取消与恢复通过**：提交 20,440 字符的合成原文，在仍显示翻译进行中时按 Esc；300 毫秒后恢复等待翻译，历史保持 5 条，继续观察 1.2 秒没有迟到结果或历史增加。清除长原文后，通过翻译按钮再次提交 `Hello, world.`，仍返回 `你好，世界。`，总耗时约 2.33 秒、首字约 2.08 秒，历史增至 6 条，确认取消后可正常恢复。
- 较早的便携构建也完成过短句和 876 字符的合成原文翻译；该观察与上面的最终文件哈希分开。所有耗时均为当前设备、网络和账号下的单次手动文本翻译观察，不是 OCR 全流程或普遍性能基准。0.3.1 的旧 Codex CLI 翻译记录单独保留。
- 真实账号切换与远程撤销尚未实测；自动化覆盖不替代这些设备结论。
- 本轮未实测安装 / 覆盖升级、系统自启、截图完成与取消、多显示器、macOS 真机或移动端。iOS / Android 仍使用自行配置的 API，现有已发布二进制仍为 0.2.0。

## 模拟与设备测试的边界

OCR 测试运行实际打包的 Worker、WASM 和语言模型。常规翻译测试使用本机 HTTP/SSE 服务，没有调用真实付费 API；测试速度不能代表云端服务延迟或翻译质量。0.3.1 曾单独测试真实 Codex 订阅，记录仅适用于旧接入；0.4.0 官方 OAuth 与订阅推理的验收另行记录。

原生接口测试模拟 Tauri 命令与事件，不能替代操作系统截图、窗口可见性、权限、全局快捷键或菜单行为。截图 DOM 被清空不代表原生截图窗口已隐藏，需另行验证窗口完成或取消后的可见性。Mac 界面预览也使用模拟接口。

Windows 曾收到白屏且无法退出的反馈，重启后未复现当时故障，因此尚不能确定原始根因。0.1.1 已加入独立启动恢复界面、存储保护、原生退出、就绪超时和 WebView2 故障监测，并验证实际退出；没有通过清空用户数据规避问题。
