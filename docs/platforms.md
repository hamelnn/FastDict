## 移动端开发

移动端提供底部导航、原生图片选择、主动粘贴和译文系统分享。分享功能用于发送译文；接收其他 App 分享的截图、跨应用悬浮窗、全局截图快捷键和快捷指令尚未实现。

Android 使用系统文档选择器，iOS 使用 PHPicker。图片经过方向修正和尺寸限制，再交给共享本地 OCR。系统选图暂时遮挡应用不会取消任务；主动切到后台会停止 OCR / 翻译并保留已有文字。

环境、打包和安装见 [移动端说明](mobile.md)，原生编译与设备测试范围见 [验证记录](validation.md)。
